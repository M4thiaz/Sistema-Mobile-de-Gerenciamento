= Descrição do Sistema =

O BROE é uma aplicação mobile desenvolvida para simular uma plataforma de compra e venda de produtos. O sistema permite que usuários visualizem, pesquisem e gerenciem produtos, além de realizar o gerenciamento de usuários por meio de operações de cadastro, consulta, edição e exclusão.

A aplicação foi desenvolvida com o objetivo de aplicar conceitos de desenvolvimento mobile, navegação entre telas, componentização, gerenciamento de dados e operações de CRUD.

= Instruções para Execução =

1. Clonar o repositório
git clone https://github.com/M4thiaz/Sistema-Mobile-de-Gerenciamento

2. Acessar a pasta do projeto
cd Sistema-Mobile-de-Gerenciamento

3. Instalar as dependências
npx expo install --fix

4. Executar o projeto
npx expo start

Após iniciar o projeto, é possível executá-lo utilizando um dispositivo físico com o Expo Go ou um emulador Android/iOS compatível.
